# 📝 Task Flow Web API

A RESTful Web API built with **ASP.NET Core** for managing tasks (CRUD operations). This project allows users to create, read, update, and delete tasks efficiently.

---

## 🚀 Features

- **Get All Tasks:** Retrieve a list of all existing tasks.
- **Get Task by ID:** Fetch specific task details using its unique identifier.
- **Create Task:** Add new tasks with details like `Title` and `IsCompleted` status.
- **Update Task:** Modify task status or title by ID.
- **Delete Task:** Remove a task from the system.

---

## 🛠️ Tech Stack

- **Framework:** .NET 10 / ASP.NET Core Web API
- **Language:** C#
- **API Documentation:** Swagger / OpenAPI
- **IDE:** Visual Studio 2026
